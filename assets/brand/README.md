# Marca de GuionAR

**Línea activa**: lo leído atenuado, la línea actual plena, lo próximo
intermedio, y la marca de lectura ámbar.

| Archivo | Uso |
|---|---|
| `../guionar.svg` | App icon (launcher, `.desktop`, ventanas, portfolio) |
| `guionar-16.svg` | Máster de 16 px: favicon, menús, ícono de ventana chico |
| `guionar-mono.svg` | Símbolo de un color (`currentColor`): web, sellos, fondos claros |
| `../tray/guionar-tray.svg` | Tray (sin estados: la bandeja no los tiene) |

Sistema compartido con ParlAR: rejilla 64 con módulo 4, baldosa 56×56 en
(4,4) con radio 14, barras de 6 u con extremos redondos, un solo acento.
GuionAR usa barras **horizontales** (lectura); ParlAR, **verticales** (voz).
Colores: baldosa `#101114`, líneas `#5C5E64` / `#FFFFFF` / `#9C9EA4`,
marca `#FFC45C`.
